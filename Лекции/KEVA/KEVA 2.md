# WEB
**url** - uniform resourse locator
*протокол*>*домен*>*путь*>*query параметры*>*фрагмент*
**urn** - указатель на определенный объект
## Разведка
- **изучение** структуры как нормального пользователя
- **разведка** - поиск и анализ уязвимостей
- **выбор** вектора атаки
- **создание** эксплойта
- **эксплуатация**
- **получение флага**
## Инструменты
### Языки
- *Python*
- *SQL*
- *JavaScript*
- *Bash*
### Утилиты
- *Dirb/Gobuster/ffuf* (фаззинг)
- *sqlmap* (автоматизация SQL-инъекций)
- *hashcat* (воссстановление по хэшам)
- *wfuzz* (фаззинг и брутфорс)
### Программы
- *burp suite*
- *postman* (тесты API)
### Burp Suite
- *proxy* - запросы и ответы направляются через него для редактирования/просмотра
- *repeater* - позволяет легко изменять один запрос
- *intruder* - прстой брутфорсер
- *tartget* - карта сайта
- *collaborator* - внешний сервер
- *scanner* - встроенный сканер уязвимостей
## Уязвимости
- *server-side* - уязвимость на сервере
- *client-side* - уязвимость на клиенте
### SQLi
уязвимость позволяющая модифиировать sql запрос к базе данных
### SSRF
server-side request forgery - подделка запросов на стороне сервера. Позволяет серверу делать запросы на внутренние ресурсы или внешние
### Web cache deception
обман веб-кэша. Уязвимость связанная с обходом правил кэширования страниц. С ее помощью можно украсть информацию жертвы
### Path traversal
обход путей - уязвимость связанная с недостатком фильтров пользовательского ввода. Позволяет открывать файлы на сервере
### XSS 
межсайтовый скриптинг. Позволяет добавить вредоносный JS код
### CSRF
подделка межсайтовых запросов
### CSWSH
