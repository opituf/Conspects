# OSINT
**osint** - поиск информаци из общественных источников
разделяеться на 3 категории: *поиск локаций, объектов, людей*
**инстрменты:**
- поисковые системы
- нейросети
- GeoSpy

# FORENSIC
**forensic** - расследование инцидентов
*виды:*
- **computer forensic** - работа с образами дисков и логами системы
- **network forensic** - работа с сетевым стеком
## Сетевая база
для обмена информацией в сети используются *пакеты*
*пакеты* имеют свои сегменты, в виде адресов, количества данных и прочего
*tcp/udp* - протоколы передачи
**tcp** - протокол передачи сначала устанавливающий связь через 3 рукопожатия, проверят целостность пакета и факт его доставки
**udp** - протокол который просто посылает пакеты на определенный адрес без проверок

# STEGANOGRAPHY
**stega** - способ скрытой передачи информации при котором факт передачи не является известным(нужно скрыть не только информацию но и факт ее передачи)
*факты о расширениях*:
- операционная система решает, какой программой открыть файл, по расширению файла
- программы смотрятна структуру файла и ищут там нобходимые данные
- каждое расширение файлов имеет определенную струтуру
- в начале и конце каждого файла есть сигнатуры
**инструменты(утилиты)**:
- file - называет расширение
- exiftool - дает посмотреть и изменить метаданные[^1]
- hexedit - показывает файл в hex формате
- strings - 
- binwalk - позволяет вытащить файл из другого файла(==применение: binwalk -e==)
